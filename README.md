# JavaFX Calculator

A simple calculator application developed using JavaFX.  
This calculator can perform basic arithmetic operations like:

- Addition
- Subtraction
- Multiplication
- Division

---

# Project Information

- **Project Name:** JavaFX Calculator
- **Language:** Java
- **Framework:** JavaFX
- **IDE:** NetBeans

---

# Features

✅ User-friendly interface  
✅ Basic arithmetic calculations  
✅ Clear button to reset input  
✅ Stylish light purple background  
✅ Non-editable display field  

---

# GUI Layout

| Button Types | Buttons |
|---|---|
| Numbers | 0 - 9 |
| Operators | + , - , * , / |
| Functional Buttons | = , C |

---

# How It Works

1. User clicks number buttons.
2. User selects an operator.
3. User enters second number.
4. Press `=` to see the result.
5. Press `C` to clear everything.
